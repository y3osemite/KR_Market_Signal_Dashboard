# 📊 매수 시점 신호등 (Market Signal Dashboard)

> 한국 주식 매수 타이밍을 판단하기 위한 3가지 핵심 지표 모니터링 대시보드

---

## 🎯 개요

중동 지정학적 리스크, 고환율, 외국인 수급 변화가 동시에 발생하는 시장 환경에서,
**언제 한국 주식을 매수해야 하는가**를 판단하기 위한 실시간 신호 모니터예요.

복잡한 시장 분석을 3가지 핵심 지표로 단순화해서,
초보 투자자도 한눈에 매수 타이밍을 파악할 수 있도록 설계했어요.

---

## 🚦 3가지 매수 신호

| 지표 | 매수 신호 기준 | 데이터 소스 |
|------|--------------|------------|
| WTI 국제유가 | **$90 이하** | Yahoo Finance |
| USD/KRW 환율 | **1,450원 이하** | Frankfurter API |
| 외국인 코스피 순매도 | **축소 or 순매수** | 추정값 (유가·환율 기반) |

### 종합 판단 기준
- ✅ **3개 모두 달성** → 분할매수 시작 고려
- ⚠️ **2개 달성** → 소량 선취매 고려, 나머지 신호 대기
- ❌ **1개 이하** → 관망. 방어 포지션(금 ETF 등) 유지

---

## ❓ 기준값과 데이터 소스에 대한 솔직한 설명

### 왜 외국인 수급은 실시간이 아닌 추정값인가

한국거래소(KRX)의 외국인 순매도 실시간 데이터는 **공개 무료 API가 존재하지 않아요.** 접근하려면:

- KRX 정보데이터시스템 유료 구독
- 증권사 API (키움, 한투 등) — 계좌 개설 + 별도 신청 필요
- 네이버/다음 금융 크롤링 — 이용약관상 자동화 수집 금지

브라우저에서 직접 실행되는 단일 HTML 파일 특성상 인증이 필요한 API를 연결하기 어려워요.
대신 **유가와 환율이 높을수록 외국인 매도 강도가 강해지는 역사적 상관관계**를 기반으로 추정값을 계산해요.

> 📌 **정확한 외국인 수급은 매일 장마감 후 확인하세요:**
> [KRX 정보데이터시스템](http://data.krx.co.kr) → 투자자별 매매동향

---

### 왜 $90, 1,450원을 기준값으로 쓰는가

**이 수치들은 과학적으로 검증된 임계값이 아니라, 판단을 위한 참고 기준이에요.**

**WTI $90 기준:**
- 이란-미국 전쟁 발발 직전 유가는 약 $67 수준이었어요
- $90은 전쟁 전 대비 약 34% 높은 수준으로, 시장이 에너지 충격을 어느 정도 흡수한 구간이에요
- 역사적으로 $90 이하에서 글로벌 경기 둔화 우려가 완화되기 시작하는 경향이 있어요
- 단, 시장이 $89까지 왔다가 다시 급등할 수도 있고, $95에서 이미 바닥을 찍을 수도 있어요

**USD/KRW 1,450원 기준:**
- 현재(2026년 3월) 환율은 1,480~1,495원 수준이에요
- 1,450원은 한국은행 시장 안정화 개입 효과가 가시화되는 심리적 저항선으로 판단했어요
- 외국인 입장에서 환율이 1,450원 이하로 내려오면 원화 자산의 환차손 우려가 줄어들어 재진입 유인이 생기는 구간이에요
- 이 역시 컨센서스가 있는 수치가 아닌 판단 기준이에요

> ⚑ **핵심:** 이 대시보드의 신호는 "지금 당장 사세요"가 아니라 "이 조건들이 충족됐을 때 매수를 *고려해볼 수 있다*"는 필터예요. 기준값은 🔧 커스터마이징 섹션을 참고해 본인 판단에 맞게 수정할 수 있어요.

## ✨ 주요 기능

- **실시간 데이터 조회** — 버튼 클릭 시 즉시 최신 데이터 반영
- **자동 새로고침** — 토글 스위치로 30분마다 자동 업데이트
- **신호등 시스템** — 각 지표별 녹색/노란/빨간 상태 표시
- **종합 판정 배너** — 3개 신호 달성 여부에 따른 자동 판단
- **진행도 바** — 목표까지 얼마나 남았는지 시각화
- **단일 HTML 파일** — 설치 없이 브라우저에서 바로 실행

## 🛠 기술 스택

- **Vanilla HTML/CSS/JS** — 프레임워크 없음, 단일 파일
- **Yahoo Finance API** — WTI 유가 (CORS 프록시 경유)
- **Frankfurter API** — USD/KRW 환율 (무료, 키 불필요)
- **Google Fonts** — IBM Plex Mono, Noto Sans KR

---

## ⚠️ 주의사항

- **외국인 수급 데이터**는 실시간 KRX API 없이 유가·환율 기반 추정값이에요. 정확한 값은 장마감 후 [KRX 정보데이터시스템](http://data.krx.co.kr)에서 확인하세요.
- 이 대시보드는 **정보 제공 목적**이며 투자 권유가 아니에요.
- 제시된 신호 기준값($90, 1,450원 등)은 참고 기준이며, 시장 상황에 따라 직접 수정할 수 있어요.
